# zk-banner-staging

Временна витрина за клониране на рекламни банери между пазарите на
Издателство „Златен Ключ“ (BG → RS / HR / BA / RO).

Репото има две задачи:

1. **Генериране.** Скриптът `tools/clone_banners.py` взима изходен банер,
   превежда текста върху него на целевия език и записва готовия банер.
   Пуска се в GitHub Actions, така че не зависи от включен компютър.
2. **Публични линкове.** Meta не приема изображения от Google Drive, защото
   Drive иска вход и връща HTML вместо файл. Готовите банери се подават на Meta
   през raw линк от това репо.

Google Drive остава хранилището на криейтивите. Тук файловете са временни.

## Как работи

```
jobs/КНИГА_ПАЗАР_ДАТА.json   →   GitHub Actions   →   ПАЗАР/КНИГА/ДАТА/*.png
                                                       + manifest.json с линковете
```

Качването на файл в `jobs/` пуска обработката само̀. Workflow-ът може да се
пусне и ръчно от таб **Actions** → *Клониране на банери* → **Run workflow**.

Форматът на задачата е описан в [`jobs/_schema.md`](jobs/_schema.md).

## Папки

| папка | какво има |
|---|---|
| `source/<КНИГА>/` | изходните банери (обикновено BG) |
| `covers/` | локализирани корици на книгите по пазари |
| `fonts/` | шрифтове за режим `overlay` |
| `jobs/` | задачи |
| `<ПАЗАР>/<КНИГА>/<дата>/` | готовите банери и `manifest.json` |

## Имена

Папки: `<ПАЗАР>/<КНИГА>/<дата>/`
Файлове: `КНИГА_ПАЗАР_формат_ъгъл` — ъгълът с една-две думи, без размер и без
версия в името.

Пример: `RS/RSEXCEL/2026-10-28/RSEXCEL_RS_banner_bolka.png`

## Ключът на OpenAI

Ключът **никога не влиза в репото**. Чете се от променливата `OPENAI_API_KEY`:

- в GitHub Actions — от **Settings → Secrets and variables → Actions**;
- на компютъра — от променлива на средата (`setx OPENAI_API_KEY "…"`).

## Локално пускане

```bash
pip install -r tools/requirements.txt
python tools/clone_banners.py jobs/RSEXCEL_RS_2026-10-28.json --dry-run
python tools/clone_banners.py jobs/RSEXCEL_RS_2026-10-28.json
```

`--dry-run` проверява задачата и отпечатва промпта, без да вика API и без да
записва файлове. `--force` презаписва вече генерирани банери. `--only ТЕКСТ`
обработва само банерите, чието име съдържа този текст.

## Поддръжка

Репото е публично, за да може Meta да дърпа изображенията. Не слагай в него
нищо, което не бива да се вижда: ключове, лични данни, вътрешни документи.

След като банер е качен в Media Library на Meta, файлът тук вече не е нужен и
може да се изчисти.
